# Known limitations and proof boundaries

The complete source supplies executable-design values and implementation instructions, but does not contain a built Unity project or final media. The exact selected toolchain has not been jointly built here. No actual battle win rates, Android install, live purchase/ad/consent traffic, device performance, commercial demand or legal signoff is claimed.

V001 references include inaccurate HUD amounts and extra decorative UI motifs; use them only for style. Final lighting/shadow/art/layout execution is explicitly decided from real placeholder captures at P001, not needed for CORE001. A generated paintover is not automatically geometry-perfect or a store screenshot.

The finite Medal catalogue and short campaign limit monetization/replay depth. A good local game is not proven profitable. Local save tampering and delayed recognition of offline purchase refunds are accepted scope tradeoffs. Reinstall/device change can lose progression; purchase restore is separate.

Actual publisher identity, final name/package/domain, licensed tool/host access, ABI-capable test environment, service credentials, output rights and region-specific privacy/retention review are unresolved external inputs with phase-specific blockers. None is secretly fabricated.

Historical archives are included for traceability only. This handoff does not contain a verbatim export of every chat message; DECISIONS and SUPERSESSIONS record the relevant design/workflow evolution, while the original prior source ZIPs preserve their exact bytes.
